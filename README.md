# Nesma Portfolio

Lightweight React + Vite marketing portfolio designed for Vercel.

## Direction
- Marketing & account management
- Content ideation
- AI image creation
- AI video creation
- Youthful, clean and professional visual style

## Brand colors
- #093C5D
- #3B7597
- #6FD1D7
- #FFFFFF

## Editing content
Most editable portfolio copy and project placeholders live in `src/data.js`.
The main page structure lives in `src/App.jsx`.
Visual styling is in `src/styles.css`.

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
